# AU-JRC-Calendar-App

# 🏫 AU-JRC School Activities Calendar

> **Stay informed. Be involved.**  
> An interactive, responsive, and centralized school calendar web application designed for students, faculty, and administrators at **Arellano University - Jose Rizal Campus (AU-JRC)**.

---

## 📌 Project Overview

The **AU-JRC School Activities Calendar** is a client-side web application built to streamline campus event management[cite: 1]. It provides a single platform to view upcoming academic, sports, cultural, and student council events[cite: 1]. The portal features real-time organization filtering, multiple calendar view perspectives (Month, Week, List)[cite: 1], an event details modal[cite: 1], an announcements bulletin[cite: 1], and a dedicated administrative management portal[cite: 1].

---

## ✨ Key Features

### 📅 1. Interactive Multi-View Calendar
* **Month View:** Visual grid displaying days of the month with color-coded event badges showing organization icons[cite: 1].
* **Week & List Views:** Alternative layouts tailored for quick schedule reviews[cite: 1].
* **Month Navigation:** Move forward and backward across months using controls (`< April 2025 >`)[cite: 1].

### 🎯 2. Organization Filtering System
Filter events dynamically by student organizations and departments[cite: 1]:
* 🎓 **SSC** (Supreme Student Council)
* 💻 **ICT** (ICT Club)
* 🩺 **RCY** (Red Cross Youth)
* 🏆 **SPORTS** (Sports Development Council)
* 🌿 **NSTP** (NSTP Office)
* 🎖️ **ALUMNI** (Alumni Association)

### 🔍 3. Real-Time Search & Event Details
* Search events instantly by title, location, or keyword[cite: 1].
* Click any calendar event to open a modal window displaying comprehensive event metadata: date, time, venue, description, eligibility requirements, and contact personnel[cite: 1].

### 📢 4. Campus Announcements
* Dedicated updates tab for critical schedule alterations, venue shifts, emergency advisories, and official university memos[cite: 1].

### 🔐 5. Administrative Control Center
* Secure admin authentication to post new events and publish announcements[cite: 1].
* Delete outdated or canceled events directly from the dashboard[cite: 1].

## 🛠️ Built With

* **HTML5** – Semantic markup and accessible site structure
* **CSS3** – Custom styling with Flexbox, CSS Grid, media queries, and root design variables matching AU brand colors (Navy & Gold)
* **JavaScript (Vanilla ES6+)** – DOM manipulation, dynamic data rendering, modal handling, and state management
* **Font Awesome v6** – Vector icons for UI elements and organization tags
